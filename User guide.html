Start and installation

Extract the full distribution ZIP. For portable use, open App/ExperimentDesigner.exe. To install for your Windows account, open Setup/ExperimentDesigner.Setup.exe, review the destination and select Install / update. The package includes its own Windows runtime. Keep its App and Runtime folders together. The installer can create a desktop shortcut.

To remove an installed copy, close the app, rerun Setup, choose the same destination and select Remove installation. Unknown or modified files and study projects remain. Save your study files in a separate Documents/study folder.

Use Light mode / Dark mode in the header to switch appearance. Your choice is remembered; switching does not reload animal records or discard pending edits.

1. Configure the study

  1. Select Study and choose RCBD, completely randomized or conventional allocation.
  2. Select the experimental unit: pen or cage. Set replicates per treatment and animals per experimental unit.
  3. Enter treatments in the intended order using unique IDs, or import a treatment table. Labels are optional. The app displays the treatment ID wherever a label is left blank.
  4. Select Apply settings to record the study configuration. Add/remove or Move up/down changes treatment order only as a draft until applied.

The required animal count is treatments × units per treatment × animals per unit. Changes create input revisions; earlier allocations retain their own inputs.

Prepare sheets and labels before allocation day

  1. Apply Study settings with treatments, replicates and animals per pen or cage. Animal IDs and weights are not needed yet.
  2. Open Allocation → Overview, choose the housing range and enter a layout seed. The range must contain exactly treatments × replicates numbers. For three treatments and four replicates, 101–112 uses 101–103 for replicate 1, 104–106 for replicate 2, and so on. Treatments are randomized within each replicate.
  3. Select Prepare layout. Review the Prepared layout tab and Save the project. Print layout / labels opens Excel export, printable HTML, print preview and Print / PDF. Prepared-layout Excel contains only the Layout worksheet. The print-view dropdown still offers blank allotment sheets and housing labels separately.
  4. On allocation day, reopen this saved project, use Enter animals to type IDs and BW values (then Review entries, Validate and preview, and Apply reviewed import), or import IDs and body weights from a file; the program automatically selects the heaviest animals under the active sex-composition rule; then Generate allocation. A different animal-allocation seed is allowed: the saved layout seed keeps the prepared treatment locations unchanged.
  5. If treatments, replicates, animals per unit or housing range change, prepare a replacement layout and reprint the affected sheets. Replacing a layout warns that previous labels may no longer match.

Preparation records no animal allocation. Generate allocation without an existing layout prepares one automatically. Final exports list each allocated animal’s actual pen or cage number. Excluded animals have no destination. Unmapped historical results require housing assignment before final export.

2. Import and automatically choose animals

  1. Select Animals → Import animals. CSV, TSV, XLSX and XLSM are supported. Workbook macros and formulas are not executed.
  2. Choose the sheet/table, header row and complete animal row range. Map Animal ID and BW. BW values are imported exactly as entered; use consistent values throughout a study. Enable stored integer IDs for numeric IDs in Excel. Review Validate and preview, then Apply reviewed import.
  3. Every imported record remains in the source pool. Ignore sex selects the heaviest animals overall. Configured sex modes select the heaviest animals within the specified male/female counts. Unused animals are EX. Weight ties use Animal ID then immutable Record ID. No Include/Exclude clicking or selection commit is required.
  4. If the pool is smaller than the required count, import or enter more animals. The supported pool limit is 100,000 animals. Changing study counts, sex composition, weights or sex updates automatic selection.
  5. Search, filter, scroll and change page size to review records. Selected and EX are shown in Status. Go to Allocation when ready.

Original sources, measurements and the automatic selection rule are retained in the project. Existing projects with manual selections retain their historical decisions; a new animal import uses automatic selection.

Animal sex and composition

In Study, choose Sex allocation: Ignore sex (the default), Balance sexes, or Separate sexes. The relevant composition controls appear below the dropdown. Animal entry, record correction and import support an optional Sex field. Male/M/B and Female/F/G are accepted case-insensitively. Blank, U, UNK, Unknown, NA and N/A mean Unknown. A Sex or Gender heading suggests the optional import mapping; review it before applying. Invalid values appear in the import preview.

Ignore sex: select the heaviest required animals overall and allocate as before. Unknown is allowed.

Separate sexes: choose the number of male replicates. The female count is total replicates minus male replicates and updates automatically. Male replicates come first, followed by female replicates. Every replicate contains all treatments. Zero male replicates or zero female replicates is allowed for a single-sex study.

Balance sexes — Same in every pen: choose males per pen. Females per pen is the study's animals-per-unit count minus males per pen and updates automatically. Every pen uses exactly that composition; no 50:50 ratio is imposed.

Balance sexes — Two groups: choose the last replicate in group 1, then choose males per pen for each group. The screen shows both replicate ranges and the automatically calculated female counts. Both groups keep the same total animals per pen or cage. For six replicates with 18 animals per pen, a split at 3 could use 9 male + 9 female in replicates 1–3 and 6 male + 12 female in replicates 4–6.

Count dropdowns suggest common values; larger studies can type an exact whole number. Required male and female totals update from your treatment, replicate and composition settings. Apply settings to record them. Configuring explicit sex counts enables automatic selection: the heaviest males and heaviest females are selected within the specified requirements. An animal of the other sex or Unknown cannot fill a shortage. If either sex is insufficient, allocation is blocked with required and available counts; import more animals, correct records or adjust the composition. All unused animals remain EX.

Blocked designs rank selected animals by body weight within sex; CRD randomizes within the composition constraints. Swaps must preserve each pen's specified composition. Changing sex composition does not move the prepared treatment and physical pen locations. Changing treatments, replicates, animals per unit or housing range may require a new layout and labels. The initial-BW target remains strictly p > 0.6.

The Animals table includes Sex, a Sex filter and pool totals. Assignments include Sex; pen BW summaries include Male, Female and Unknown counts. Excel and printed reports include the composition rule, ranges and sex counts. Blank allotment sheets include a Sex field.

Projects without sex still open in Ignore mode. Projects from the first sex-feature preview retain their automatic composition and allocation history, labeled Automatic mix (previous preview) or Automatic (previous preview). Choose an explicit pattern/count and Apply settings to adopt the new requirements. Their earlier sex-composition rule remains available; new RCBD allocations use ranked BW subgroup balancing. Projects saved with the new composition settings require this updated app.

3. Allocate and review

  1. Select Allocation → Overview. Enter an unsigned whole-number seed, then Generate allocation. No run reason is needed; History records the action and seed automatically. A disabled action has a visible setup/selection blocker.
  2. Review Overview, Assignments, Pen BW, Treatment balance and Diagnostics. Overview uses actual current block CV and treatment mean BW; original attempt records are available in Diagnostics. Its plot starts at zero. Scroll compact views to see all metrics and treatments. Cancellation or a failed attempt retains the previous completed result.
  3. The revision selector controls every result view and export. Historical results and results based on earlier inputs are labeled.
  4. To swap, choose the active current-input revision, open Swap animals, choose two records and supply a reason. Review the affected units/blocks and apply only a passing preview.
  5. To map housing, enter exactly one physical unit per allocation unit, using unique physical IDs, full scoped locations, sufficient capacity and replicate eligibility. Preview with its independent mapping seed before applying.

Changed swap/mapping inputs invalidate their previews. Applied operations create logged revisions. Choose Use this result with a reason to make an earlier result active.

BW balance is descriptive at the experimental unit level. It does not analyze later study outcomes. The versioned generator is not Excel RAND; edited results require the original seed and ordered edit history for replay.

New projects use .experimentproj. Existing .poultryproj files remain supported. Save updates an opened legacy project in place. Use Save As to save it under a new filename with the .experimentproj extension. Saved balancing settings, notes, layouts and history are preserved even though optimization and notes controls are no longer shown on Study.

4. Save projects and recover

Save writes a .experimentproj containing prepared layout, settings, original sources, decisions, revisions and run/edit/map history. Save (Ctrl+S) asks for a filename on the first save and updates that file on later saves. File → Save As (Ctrl+Shift+S) lets you choose another filename or confirm replacement of an existing project file. File also contains New study (Ctrl+N), Open (Ctrl+O) and Recover backup. User guide is in the sidebar. Saved, Unsaved changes, Saving and Save failed are explicit; a project without a filename is not labeled Saved. A title/status indicator marks unsaved settings or decisions. Exporting a report does not save the project.

New, Open and Close offer save/discard/cancel for dirty work. Routine settings, selection and generation actions receive descriptive history labels automatically. Reasons for corrections, swaps and housing changes remain available in their review dialogs. There is no autosave; save regularly. Saves check whether the disk file changed externally and preserve the preceding saved version as .bak.

For recovery, select File → Recover backup and choose the main project's filename. The backup is validated and must be saved to a new path. Recovery restores previously saved history, not unsaved work. A failed open leaves the current project intact.

Read replicate and cage body weights

The Replicate BW sheet lists allocated animal count, mean BW, minimum BW, maximum BW, sample SD and sex counts for each replicate in study order. Use it to inspect the weight gradient across RCBD replicates. Different sex compositions can affect comparisons between replicate groups, so read the sex counts alongside the weights. Unit BW and the Pen BW screen show the actual minimum and maximum BW within each cage, alongside mean and SD.

Automatic selection prioritizes the heaviest animals under the active sex requirements. Lighter animals can still be used when needed to fill the study. RCBD balancing uses that fixed selected group: it does not replace selected animals with light EX animals to obtain a better balance score. RCBD keeps the existing descending BW blocks within each sex sequence. Inside each block, adjacent weight ranks form subgroups of the eligible treatment count. Each subgroup contributes one animal to each eligible pen, giving pens comparable weight distributions. Candidate assignments balance pen means; among candidates meeting the automatic 0.5% block CV target, the app prefers smaller maximum and total within-pen BW ranges. Candidate search is bounded and retains the best result found, so a global optimum is not claimed. A final randomized treatment permutation stays within the block and matching sex counts. Male/female replicate order and prepared treatment locations remain fixed. If the available weights cannot meet the automatic target within the search budget, the actual result is retained with a warning to review Pen BW and Diagnostics. No animals are substituted from EX. This is a block CV target, separate from the strict p > 0.6 treatment-balance target and one-seed repeat advice remain available. Manual swaps can alter the observed cage/replicate ranges; the exported summaries follow the chosen allocation revision.

Plain integer old pen/cage values export as numbers when exact in Excel. Leading-zero, long and textual location codes retain their exact spelling. Prepared-layout Excel always exports the Layout sheet; the preparation dialog's print-view selection controls printing/HTML.

Unit-neutral BW and saved projects

BW, mean, minimum, maximum and SD have no imposed measurement-unit suffix. New imports and manual entry retain the numbers entered, without unit selection or conversion. Previously saved values stay unchanged, including any conversions already recorded by an older import. Earlier allocations replay using their recorded grouping rule. Applying current RCBD settings or generating a new RCBD allocation records the ranked BW subgroup rule as a new input revision; earlier results remain available. Weight distributions are balanced under the available weights, fixed cage sizes and sex counts. A narrow BW block supports narrow pen ranges; an extreme animal in the heaviest selected group can still widen a pen. The app does not silently exclude that animal or claim an absolute range cutoff. Earlier contiguous-cage results keep their original rule and replay unchanged.

History and desktop controls

History shows recent real recorded actions and the complete Runs and edits, Input revisions and Source files tables. Select Source files to inspect the retained original observations. The workflow indicator marks the current step; Review / Export means output is available, not scientifically approved. Native tabs support keyboard navigation, buttons retain visible focus, and modal prompts support Escape. On reduced windows, forms and Overview scroll while tables fill the remaining space.

Review balance before export

The Allocation screen shows treatment ANOVA immediately after each completed run, across its result tabs. A p-value at or below 0.6 shows a repeat recommendation. Select Repeat with next seed to record a new allocation while retaining the previous result and prepared housing arrangement. This action advances the seed once; it does not automatically rerun until a target is reached. The recorded result remains available for expert review and export. A p-value that cannot be estimated requests review of unit body weights.

ANOVA and numeric Excel sorting

ANOVA compares pen/cage mean body weights. RCBD and conventional BW-blocked designs include replicate blocks; CRD uses a one-way treatment model. The displayed target is strictly p > 0.6, so 0.61 meets it. This is a baseline balance diagnostic, not proof of equal weights or a successful allocation. Zero-variance cases are labeled explicitly.

Plain numeric Animal IDs, Treatment IDs, pen/cage numbers and replicates export as Excel numbers. Leading-zero IDs, IDs longer than 15 digits and alphanumeric IDs remain text to protect identity and Excel precision. Sort or filter the unit table; the ANOVA panel sits outside its filter range.
