# Experiment Designer v1.1.2

First planned public open-source release for researchers running livestock trials.

- Prepare pen/cage treatment layouts and labels before allocation day.
- Import IDs and body weights, select the heaviest required pool automatically,
  and retain unused animals as EX.
- Generate reproducible seeded RCBD, CRD or conventional allocations without
  moving prepared treatment locations when repeating animal allocation.
- Review experimental-unit mean BW and baseline treatment ANOVA before exporting.
- Export final/preparation sheets with numeric Treatment IDs for Excel sorting;
  leading-zero, long and text identifiers preserve identity.
- Use a native light/dark Windows interface, saved history, complete-page print
  preview, per-user setup and the offline guide.
- MIT-licensed source, ORCID citation metadata, automated security checks and
  the current pinned .NET 10 security runtime.

Download the Windows x64 ZIP and checksum. Extract it completely, then open
`Setup/ExperimentDesigner.Setup.exe` to install or `App/ExperimentDesigner.exe`
for portable use. The included runtime removes the need for separate installation.
The binaries are unsigned; obtain them from this repository's reviewed release.

This release is a draft until the maintainer approves publishing and CI is green.
Zenodo DOI will be added after archival. Baseline ANOVA is a diagnostic, not a
guarantee of experimental success; final scientific decisions remain with users.
