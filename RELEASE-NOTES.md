# Experiment Designer v1.1.7

Application language and appearance now live in **Settings** at the bottom of the sidebar. Save remembers both preferences, while Cancel preserves the current choices. Current studies and pending edits remain intact.

- English, Spanish (Spain) and Spanish (Mexico) cover the interface, report metadata and offline guides. Wording, number agreement and regional conventions have been reviewed; researcher-entered data remain unchanged.
- The installation wizard includes language selection, the original MIT license and developer credit, destination selection, Start Menu and desktop shortcut choices, progress, cancellation/retry and launch on completion.
- The installation language becomes the initial application language. Users can change it later in Settings.
- The allocation engine, saved study history and numeric Excel identities are preserved. The Windows package retains the verified .NET 10.0.15 runtime.

## Windows download

Extract the complete **Experiment-Designer-1.1.7-win-x64.zip**. Open `Setup/ExperimentDesigner.Setup.exe` to install or update, or `App/ExperimentDesigner.exe` for portable use. Keep App, Setup and Runtime together. No separate .NET installation is required.

The Zenodo archive contains the release source. The ready-to-run Windows package and SHA-256 checksum are on GitHub Releases. Existing releases remain available.

Native Windows file/print dialogs may follow Windows display language. The package remains unsigned; physical monitor transitions and real printer jobs are not claimed as automated verification.
