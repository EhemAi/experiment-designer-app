# Experiment Designer v1.1.6

- Save updates the current project. Save As can replace an existing project after confirmation and retains a backup.
- Treatment labels are optional in study setup and import. Reports and allocation views use the treatment ID when a label is blank.
- New Study opens the naming dialog immediately from an untouched launch. Real edits still trigger the save prompt when you leave the study.
- The Windows package bundles the .NET 10.0.15 security runtime.

## Windows download

Extract the complete **Experiment-Designer-1.1.6-win-x64.zip**. Open `Setup/ExperimentDesigner.Setup.exe` to install or update, or `App/ExperimentDesigner.exe` to run without installing. The package includes the runtime and a SHA-256 checksum is available.

The Zenodo archive contains the release source. The Windows package is on GitHub Releases.
