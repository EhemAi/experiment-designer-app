Experiment Designer 1.1.2 - Windows x64

Extract the entire ZIP before running. Keep App, Setup and Runtime together.

Portable use: double-click App/ExperimentDesigner.exe.
Install for your account: double-click Setup/ExperimentDesigner.Setup.exe, review
the destination, then click Install / update. Administrator access is not needed.
The installer adds Experiment Designer to Start and Windows Installed apps,
including an uninstall option. A desktop shortcut is optional. It uses separate release folders
for upgrades and never imports or selects your study animals automatically.

The package contains its own .NET 10 Windows runtime. No SDK or separate runtime
installation is needed. Do not copy just the EXE out of its App folder.

Read App/User guide.html, also available using User guide in the application.
Save projects and reports in your Documents/study folder. Save the project
explicitly; exports do not save pending changes. There is no autosave.
New project files use .experimentproj. Existing .poultryproj projects can be opened
and saved under the new extension without losing their inputs, layouts or history.
Use Light mode / Dark mode in the app header to switch appearance; your choice is remembered.

To remove an installed copy: use Windows Settings > Apps > Installed apps,
or close the application, run Setup again, choose
the same installation folder and click Remove installation. Only unchanged
verified application files are removed. Unknown/modified files and projects
are preserved. A failed removal can be retried after closing the app.

This build is not code-signed. Use Windows Installed apps or the included Setup
application to manage an installed copy. The manifest checks corruption;
it is not an authenticity signature. Distribute the archive with its SHA-256 file.

Windows print preview/PDF depends on configured printers. For PDF, choose
Microsoft Print to PDF. Printable HTML provides browser printing as an alternative.
This app supplies allocation and descriptive initial-BW balance, not study outcome
analysis. The original macro workbook remains unchanged. Real-study subset choices
and scientific acceptance remain researcher decisions.

Font and Microsoft runtime licenses are included alongside their files.
