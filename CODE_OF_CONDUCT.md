# Code of conduct

We welcome participants regardless of background, identity, disability or
experience. Be respectful, constructive and patient. Give actionable technical
feedback, respect privacy and credit others' work.

Harassment, discriminatory language, threats, sexualized attention, publication
of private information and repeated personal attacks are not acceptable.
This applies to project issues, pull requests and other project spaces.

Maintainer Emmanuel O. Alagbe may edit or remove inappropriate contributions,
warn participants, limit interactions or ban repeat or serious offenders.
Enforcement considers impact, context and privacy and avoids retaliation.

Report conduct concerns privately using the contact details on
[the maintainer's GitHub profile](https://github.com/EhemAi). If no private
contact is available, use [GitHub's abuse reporting channels](https://support.github.com/contact/report-abuse).
Do not publish another person's private information in a report. A direct
maintainer contact can be added when one is provided.
