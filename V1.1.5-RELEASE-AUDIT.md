# Experiment Designer v1.1.5 release audit

Prepared November 4, 2026 for the maintainer-authorized update to the existing
public repository, EhemAi/experiment-designer-app. The original repository,
research inputs and private development history remain private. Release is gated
on the protected pull request and successful GitHub checks; local analysis is
not represented as a hosted CodeQL result.

## Findings and disposition

| Finding | Scope | Disposition |
| --- | --- | --- |
| Pasted research weights in development regression fixtures | Publication/privacy blocker | Replaced with independently generated synthetic public fixtures. No research workbooks, projects, observations, private validation captures or screenshots containing those observations are published. Approved production engine/application-core code is unchanged apart from whitespace and product version metadata. |
| Windows shell silently truncates long shortcut targets; native font loading also has path limits | Installer reliability | Setup validates the resulting shortcut/font paths before copying an installation, and registration revalidates. Overlong roots receive a clear request for a shorter folder. Negative tests cover rejection without creating an installation. Space/Unicode registration/update/uninstall and installed native workflows run under bounded independent temporary roots. Test cleanup preserves unknown/user files. |
| Six full-working-folder secret-scan matches | Local third-party tooling false positives | Two cryptography HPKE type declarations and four Gitleaks README/example matches, including archive copies. None are credentials. These tools are excluded from source and Windows assets. No source-secret baseline/suppressions are introduced. |
| Five advisories in the isolated current Semgrep environment | Development-tool limitation; not an application/CI/release dependency | Semgrep 1.183.0 requires `mcp==1.29.0` and OpenTelemetry 1.37.x. Four MCP advisories require 1.30.0/2.2.0, and CVE-2026-114603 requires OpenTelemetry API 1.45.1. Patched versions conflict with upstream requirements, so unsupported overrides are not used. Metrics/version checks are disabled; MCP client/server modes and inbound telemetry servers are not used. The tool and its Python environment are not committed, bundled or used in CI. CodeQL and .NET analyzers provide ongoing C# checks. |
| Semgrep partial parser/embedded shell diagnostics | Scanner coverage limitation | Zero findings across 143 rules/108 targets; approximately 99.8% of lines parsed. Six diagnostics involve modern C# constructs and PowerShell interpreted by Bash-specific workflow rules; 15 files are ignored by default patterns. Compiler/security diagnostics and native tests pass; hosted CodeQL is required separately. Valid application code is not rewritten to silence a parser. |
| Unsigned binaries and physical-device coverage | Existing distribution/testing limits | SHA-256 sidecars and verified runtime provenance are supplied. No signing certificate is configured. A second physical computer, actual printer jobs and physical monitor transitions are not automated. |

The MCP advisories in the local scanner are CVE-2026-59951,
CVE-2026-116685, CVE-2026-116684 and CVE-2026-116686. Their presence is not
reported as a clean tool-environment audit. No known vulnerabilities were found
in the application NuGet graphs or the exact CI citation requirements.

## Verification results

- **Independent public regression:** 61,131 assertions passed in the candidate
  checkout and again in a fresh final functional-source clone. Optional private
  captured Excel fixtures are absent and explicitly skipped. The synthetic suite
  covers sex quotas, heaviest-first selection/EX boundaries, all designs, BW
  subgroup distributions, deterministic replay, historic policies, import,
  exports, immutable history, housing and installer boundaries.
- **Native Windows desktop:** 737 assertions passed for the portable package and
  installed app, including idle/scroll/page-two behavior, both themes, report
  rendering and failure/cancellation preservation. No printer jobs were sent.
- **Focused native controls:** 141 assertions passed against the packaged
  apphost, including sex settings, scaled layouts, Generate policy migration,
  retained housing/history and visible unattainable-BW-target feedback.
- **Windows integration:** 16 assertions passed for registry entries, shortcuts,
  updates, long-path rejection, durable uninstaller, runtime independence and
  user/unknown-file preservation. Installed native workflow and removal passed.
- **Clean checkout:** README SDK prerequisite, restore/build, independent suite,
  locked restore, formatting/security analysis and native startup passed without
  private inputs or copied build outputs.
- **Runtime provenance:** Microsoft metadata identifies .NET 10.0.14 / SDK
  10.0.403 as the current pinned security release. SDK archive SHA-512 matches
  official metadata; all 480 packaged runtime files match that archive.
- **Package:** installer verified every manifest hash; independently checked 499
  App/Runtime manifest entries and all 519 archived files. Research inputs, private
  history, local tools, tests, source and debug-symbol payloads are absent. Startup
  uses the adjacent runtime with global discovery disabled. The final distribution
  also records the exact released public source revision.
- **Gitleaks 8.30.1:** original private history (four commits), public history and
  exact public source scanned with full redaction. No detected secrets in either
  history or public source. The entire local working folder scan covered about
  568 MB, including ignored files and first-level archive content, with only the
  six reviewed tooling false positives. Nested archive depth is not claimed as
  unlimited recursive coverage.
- **Dependencies:** official NuGet advisory queries cover Desktop, Setup and
  Checks, including transitive graphs. Five lockfiles contain project references
  only, with no third-party NuGet dependencies. The 17 exact CI Python pins pass
  pip-audit. npm audit/Bandit are not application checks because no JavaScript or
  Python application ships. The separate local Semgrep dependency audit is
  disclosed above. Runtime/font redistributable notices remain intact alongside
  MIT-licensed original source.
- **Static/code quality:** .NET security analyzers, Release builds, locked
  restores and whitespace verification pass with zero warnings/errors. Semgrep
  default/security-audit/C# packs report zero findings with the coverage limits
  above. Review found no new evaluation/shell/API/SQL/CORS surfaces; the app uses
  local constrained project/import models and bounded validation. Legacy
  allocation policies remain intentionally reachable for saved-result replay.
- **Metadata:** CFF 1.2.0 validation passes. Product version 1.1.5, release date,
  MIT license, repository, supplied author/affiliations/ORCID and Zenodo software
  metadata agree. The Zenodo description requests citation of the version used.
  Twelve third-party workflow references use immutable full SHAs with read-only
  default permissions. Existing weekly Dependabot/security settings are retained.

## Publication controls

Require successful `windows`, `citation`, `csharp`, `secrets` and
`dependency-review` PR checks, then publish from the verified public main commit.
No branch-protection bypass, private-history push or old-release overwrite is
allowed. The existing Zenodo release hook must archive v1.1.5 under concept DOI
10.5281/zenodo.23698895. Verify the actual archived source and version DOI before
adding that DOI to README/CITATION in a protected follow-up. Zenodo archives
source; the ready-to-run Windows ZIP/checksum remain on GitHub Releases.

Raw logs may contain local paths and stay private. See
[V1.1.5-RELEASE-FILES.md](V1.1.5-RELEASE-FILES.md) for the release change list.
No claim is made that testing proves absence of every defect or vulnerability.
